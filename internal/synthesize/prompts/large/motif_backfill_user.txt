Some facts in this knowledge base carry no `motifs`. Your job is to decide, for each, whether one applies.

A motif names the general REGULARITY a fact is an instance of — a mechanism, a failure shape, a pattern — independently of the fact's subject. Motifs exist so two facts about unrelated subjects can be connected when they exemplify the same mechanism. A motif is a 2-4 word lowercase kebab-case phrase.

The work item's `facts` field lists the facts. Each has a `path`, and often a `residue`: the words from the fact's own title that are NOT about its subject. The residue is a hint, sometimes a good one and sometimes noise from how the title happened to be phrased — read it as a suggestion, never as an answer.

The item's `vocabulary` field lists motifs this corpus already uses, each with `df` (how many facts carry it) and, where one has been written, a `definition`. These are drawn from facts that resemble yours, so a name that fits is more likely to be here than not.

PREFER AN EXISTING NAME. A motif that only one fact ever carries connects nothing, and the axis is only worth anything when the same name reaches two facts an author would not have thought to link. If a vocabulary entry describes the mechanism, use it exactly as spelled. Mint a new name only when nothing offered fits.

ZERO IS THE RIGHT ANSWER OFTEN. Many facts are about a particular thing and instantiate no general regularity at all. Return no motifs for those. A wrong motif is worse than none: it will be used to decide that two unrelated facts describe the same mechanism.

Do NOT return a motif that:
- restates the fact's own subject — its entity, its area, or words from its path. Such a motif says nothing the fact has not already said about itself, and it is discarded on write.
- describes the fact's topic rather than its mechanism ("database-indexing" is a topic; "write-amplification" is a mechanism)
- is a judgement or a recommendation ("avoid-global-state")
- names the fix rather than the failure — if the fact describes a problem and its remedy, the motif names the problem's shape ("unmonitored-expiry", not "automatic-renewal")
- you would only understand having read this one fact

Never give one fact two phrasings of the same regularity. Pick the better one.

At most 3 per fact, and fewer is normal.

Respond as JSON (no markdown wrapping):
{
  "assignments": [
    {
      "path": "<the path, exactly as given>",
      "motifs": ["existing-or-new-motif"]
    }
  ]
}

Every fact you were given must appear exactly once in `assignments`, with an empty `motifs` array where none applies.
